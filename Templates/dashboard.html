Project Analysis

Patient Data Analysis

Patient records are processed using Pandas and NumPy before being passed to the machine learning models.

Data Preprocessing

Missing values, numerical variables, categorical variables, and model input features are prepared before prediction.

Classification

Scikit-learn classification models are used to determine the predicted disease-risk category.

Risk Score Generation

Prediction probabilities are converted into an easy-to-understand risk score from 0 to 100.

Feature Engineering

Relevant health and lifestyle variables are prepared as model features for disease prediction.

Statistical Analysis

Dataset distributions, model performance, and prediction probabilities are analyzed to generate useful analytical insights.

Data Visualization

Matplotlib and Seaborn are used to create distributions, feature importance, and classification visualizations.

Model Evaluation

Classification models are evaluated using appropriate performance metrics and confusion matrices.
